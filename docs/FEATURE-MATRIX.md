# Feature and compatibility matrix

Remote-service boundary: SSH, NFS, SMB/CIFS and S3-compatible storage are external services operated by their owners.

Status meanings:
- **Implemented**: code path exists.
- **Textual**: exposed through the keyboard-first terminal interface.
- **Automated**: covered by hardware-independent tests or CI checks.
- **Operator validation**: maintainer-run checks requiring ISO boot, physical media, network equipment, laboratory machines or live external services. These are separate from software CI, but they are required release-acceptance gates and must be recorded by the repository owner.

Do not infer support from a package being installed. Hardware, firmware,
filesystem and network support must be verified on the actual target. ISO
creation and laboratory validation are operator-owned steps.

Artifact byte counts and SHA-256 digests are recorded in the manifest and verified before restore/publication. Repository access controls and authenticated transport provide the trust boundary.
