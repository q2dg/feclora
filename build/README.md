# Build pipeline

The initial build system will target a reproducible Fedora 43 x86_64 live ISO. Lorax / `livemedia-creator`, Kickstart, and dracut are candidates; the implementation choice must be validated on a clean Fedora builder before being treated as supported.

Build requirements, exact commands, input checksums, package versions, and artifact locations will be documented here once the first end-to-end build is verified.
